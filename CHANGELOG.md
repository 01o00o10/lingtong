# Changelog

All notable changes to LingTong will be documented in this file.

The project follows Semantic Versioning after the first public release. During
the `0.x` series, minor releases may contain incompatible API changes when they
are called out in this file and in the release notes.

### Added

### Known Limitations

- The project has not passed the complete Servlet, JSR 356, or Jakarta EE Web
  Profile TCK suites.
- A successful repository build does not establish drop-in compatibility with
  every Tomcat or TongWeb application.
