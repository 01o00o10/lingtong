# Support

Community support is provided through GitHub Issues on a best-effort basis.
Please include a minimal reproducer, LingTong version, JDK version, operating
system, relevant configuration, and sanitized diagnostic output.

The public `0.x` series has no guaranteed response time, production support,
compatibility certification, or warranty. Commercial support and licensing
may be arranged separately through the project owner's
[GitHub profile](https://github.com/01o00o10).

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not
be disclosed in a public support request.
